# Banking System Backend – Java

## 📌 Description
A Java-based backend application that simulates core banking operations such as account creation, authentication, deposits, withdrawals, and fund transfers.

## 🛠️ Technologies Used
- Java (Core Java)
- JDBC
- MySQL
- SQL

## ✨ Features
- User authentication
- Account management
- Deposit and withdrawal operations
- Fund transfer between accounts
- Transaction handling with data consistency

## 🏗️ Architecture
- Layered architecture (Controller / Service / DAO)
- Object-Oriented Programming principles
- JDBC-based database connectivity

## 🚀 Future Enhancements
- Migration to Spring Boot
- RESTful APIs
- Security using Spring Security
